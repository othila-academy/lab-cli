# Sécurité

Pour signaler une faille de `@othila-academy/lab`, n'ouvre pas d'issue publique : utilise « Report a vulnerability » dans l'onglet Security de ce dépôt. Nous répondons sous cinq jours ouvrés.

Le paquet n'a aucune dépendance et aucun script d'installation. Chaque version est publiée depuis la CI de ce dépôt, sans jeton, après validation manuelle, avec une attestation de provenance vérifiable par `npm audit signatures`.
